# Radio Widget для Noctalia

Красивый виджет радио с отдельным меню управления станциями.

## Возможности
- Воспроизведение станций через mpv.
- Отдельное меню для добавления и удаления станций.
- Управление громкостью, переключение треков.
- Панель на 30% шире.

## Зависимости
Установите пакеты:
```bash
sudo dnf -S mpv socat
# или для других дистрибутивов: apt/pacman и т.д.
